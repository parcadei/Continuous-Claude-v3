# Module: Codify & Skill Evolution

## Overview

Automatic skill generation from repeated patterns. Sub-agents write raw decisions, orchestrator aggregates and generates skills.

## Sub-Agent Pattern Recording

Sub-agents write raw decisions (no LLM call):

```python
async def record_decision(decision: str, metadata: dict):
    """Record decision to Archival Memory (cheap write)."""

    await archival_memory.store(
        content=decision,
        metadata={
            "type": "pattern",
            "source": "codify",
            "agent_id": os.environ.get("AGENT_ID"),
            "session_id": os.environ.get("SESSION_ID"),
            "task_type": metadata.get("task_type"),
            "tools_used": metadata.get("tools_used", []),
            "timestamp": datetime.now().isoformat(),
        }
    )
```

## Orchestrator Aggregation

Runs at session end (LLM-as-judge on orchestrator only):

```python
async def aggregate_patterns():
    """Aggregate patterns from Archival Memory."""

    # Get all pattern entries from this session
    patterns = await archival_memory.search(
        query="type:pattern",
        limit=1000
    )

    # Group by content hash
    grouped = defaultdict(list)
    for p in patterns:
        key = content_hash(p["content"])
        grouped[key].append(p)

    # Find high-frequency patterns
    for key, occurrences in grouped.items():
        if len(occurrences) >= 3:
            await generate_skill_candidate(occurrences)
```

## Skill Generation

Auto-generate SKILL.md when pattern hits threshold:

```python
async def generate_skill_candidate(occurrences: list[dict]):
    """Generate skill from repeated pattern."""

    # Extract common elements
    task_types = {o["metadata"]["task_type"] for o in occurrences}
    tools_used = set()
    for o in occurrences:
        tools_used.update(o["metadata"].get("tools_used", []))

    # Generate skill name
    skill_name = f"auto-{task_types.pop()}-pattern"
    skill_dir = Path(f".claude/skills/{skill_name}")
    skill_dir.mkdir(parents=True, exist_ok=True)

    # Write SKILL.md
    skill_content = f"""---
name: {skill_name}
description: Auto-generated from {len(occurrences)} occurrences
allowed-tools: [{', '.join(tools_used)}]
---

# {skill_name}

## Pattern

{occurrences[0]['content']}

## When to Use

This pattern was observed {len(occurrences)} times in tasks involving: {', '.join(task_types)}

## Generated

Auto-generated by Codify system on {datetime.now().isoformat()}
"""

    (skill_dir / "SKILL.md").write_text(skill_content)

    # Auto-add to skill-rules.json
    await add_skill_trigger(skill_name, list(task_types))
```

## Skill Lifecycle

### Auto-Pruning

Low-usage skills pruned with temporal half-life:

```python
async def prune_low_usage_skills():
    """Prune skills not used in 90 days."""

    skills = await get_all_skills()

    for skill in skills:
        last_used = await get_skill_last_used(skill.name)
        days_since_use = (datetime.now() - last_used).days

        if days_since_use > 90:
            # Check if it's an infrequent-but-valid task
            if await is_infrequent_valid_task(skill.name):
                continue  # Don't prune

            # Archive skill
            await archive_skill(skill)
            await remove_skill_trigger(skill.name)

async def is_infrequent_valid_task(skill_name: str) -> bool:
    """Check if skill is for a valid but infrequent task."""

    # Look at historical usage pattern
    usage_history = await get_skill_usage_history(skill_name, days=365)

    # If it was used successfully but infrequently (e.g., quarterly task)
    if len(usage_history) >= 2 and all(u.success for u in usage_history):
        return True

    return False
```
